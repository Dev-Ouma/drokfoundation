# Dr. Joel Okutoyi — public site

Personal and professional site for Dr. Joel Okutoyi, PhD, Senior Lecturer at Maseno University. Copy is limited to public sources; named philanthropy and constituency details are left open until confirmed.

```bash
npm install
npm run dev
```

## Photography

Drop files into `public/images/`:

| Filename | Where it appears |
| --- | --- |
| `portrait.jpg` / `.png` / `.webp` | Hero panel, home bio circle, About |
| `official-01.jpg` … `official-12.jpg` | Impact carousel + Gallery |
| `foundation-hero.jpg` (optional) | Foundation page hero |

Official photography currently ships as `portrait.png` and `official-01.png` (workshop speaking photo).
